决策级估值之前，必须先过三座桥

Owner earnings bridge

法定归母 → 持续经营 → 非现金/一次性项目 → SBC → 经营现金流 → 维护性投入 → 标准化营运资本 → owner earnings。每项都要金额、符号、税务和来源。

Net cash bridge

现金与等价物 + 可动用金融资产 − 借款 − 租赁 − 可转债 − 受限现金/客户资金 − 其他准债务。不能把融资所得全部当自由现金。

Fully diluted share bridge

期末已发行 − 库存股 + 期权/RSU + 可转债 if-converted + 配售/供股承诺。上行情景若越过转股价，必须同时改变债务和股数。

每股价值双情景

未转换偿债情景与完全转换情景并列；分别展示净现金、到期偿付、有效转股价、稀释股数和每股价值，不能混用。

第四张结构表：流通盘稀缺度与新增供给

总市值回答公司整体权益规模，不回答某一交易线真正可交易多少。小盘、A/H、多股类和带可转债的公司，必须逐交易线把法定股本、公众持股、研究代理、活跃成交与未来供给拆开。

non-treasury outstanding = issued − treasury
observable tradable-float proxy = non-treasury outstanding − disclosed controller/director actual shares − strategic blocks − explicit locked shares
float-adjusted market-cap proxy = dated price × observable tradable-float proxy
new-supply days = newly unlocked/listed shares ÷ 20-day ADTV shares
四种“流通”口径不能混写
口径回答什么研究纪律
non_treasury_outstanding已发行减库存股；每股分母起点不是交易所官方 public float，不能简称“流通股”
regulatory_public_float交易所规则下公众持股量/比例只有官方或发行人明确披露且可复核时填写；否则 unknown
observable_tradable_float_proxy扣除公开控制、战略和锁定持股后的研究代理逐项展示扣减与遗漏；通常是上限，不等于每天真实卖盘
active_supply当前窗口真正参与交易的股份结合成交、价差、借券与持有人行为推断，不能由静态股东表直接得到
新增供给日历：事件、状态和冲击必须分开
供给事件必须保存不能误读
IPO 前/基石/控制人锁定到期交易线、legal unlock 日期、股数、占解禁前流通代理比例、ADTV 天数解禁只代表可以卖，不等于已经卖
限售股、配售、供股、股份奖励与期权legal unlock、登记/上市、实际出售三个状态授权、归属、登记和成交不是同一件事
可转债、库存股与回购转换/再发行/注销路径、有效价格、最大股份与现金替代路径低于转股价不是自动还钱；库存股退出供给不等于永久注销
A/H、ADR 与多股类逐交易线股数、价格、持有人与锁定状态A 股解禁不会直接扩大 H 股流通盘；指数/港股通是需求事件
解释边界：低流通盘不是公司质量或护城河。它会同时放大上涨、下跌、跳空、逼空和融资折价；float_days_to_trade 只是成交容量代理，不是保证退出天数。

客户、供应商与上下游：谁控制收入、成本和入口

客户/供应商不是一个名称列表。必须把直接客户、付款方、终端用户、渠道、平台门卫、关键投入和替代者分开，并同时展示名称、占比、分母、期间、趋势和证据状态。未披露名称时保留匿名，不能靠传闻补齐。

customer CR1 / CR5 = 最大 / 前五客户收入 ÷ 同口径收入
supplier CR1 / CR5 = 最大 / 前五供应商采购 ÷ 同口径采购
HHI = Σ(单一对手方占比²)；只有逐家占比完整时才计算

增长变量：研究的不是最高增速，而是可验证的“变好”

观点来源于用户转述的 UP「大白不bai说」；原始视频 URL、逐字稿和时间戳尚未取得，因此归因仍待核。研究实现把直觉拆成增长加速度、经营广度、盈利/现金质量、预期差和估值五层，避免把“增速由低到高”机械写成买入。

P1 / P0 = (EPS1 / EPS0) × (PE1 / PE0)
growth acceleration = 本期可比增速 − 上期可比增速
expectation gap = 实际/最新指引 − 此前已计入路径

一般盈利公司

金融公司

晶圆代工 / 重资产

PE、P/B、EV/EBITDA 只作交叉检查，同时展示资本开支、利用率和增量 ROIC。

未稳定盈利 SaaS / AI

EV/收入、毛利、留存、SBC 后 FCF；负盈利写 N/M，不制造调整后正 PE。

内在价值区间当前价与下行/基础/上行情景距离；披露增长、折现率、净现金和摊薄low/within/high_vs_range单一 DCF 点估值、忽略可转债
同行相对估值统一增长、毛利、SBC、资本强度、币种和会计口径relative_premium/discount把主题相似当经济性可比
价格与流动性1/3/5 年回撤、200 日/40 周趋势、波动、换手、价差和相对基准拥挤、压力、趋势与更新频率跌得多等于便宜，上涨等于护城河增强
3—5 年年化回报 ≈ 每股 owner earnings 增长 + 分红/净回购贡献 + 估值倍数变化 + 汇率影响 − 稀释影响
核心纪律：低 PE、低历史分位或大幅回撤只能触发研究，不能完成研究。输入无法复算时，状态必须是 not_determinable。

状态图例：先看它属于哪一层

同一个英文词不能跨层误读。维度状态回答“该研究项是否适用”，指标状态回答“数据是否观察到”，Gate 结果回答“证据能支持到什么程度”，发布状态回答“整份报告完成到哪一步”。

维度与指标状态
层状态准确含义不能理解为
维度applicable该维度适用于本公司，必须继续检查其证据与指标该维度已经通过、表现良好
维度unknown适用性或结论因证据不足暂不能确定没有风险
维度conflicting可靠证据之间存在冲突，尚未完成调和任选一个口径即可
维度not_applicable经说明后确认该维度不适用因为没数据所以跳过
指标observed已在绑定来源、期间、单位和口径下观察到数值优秀或趋势可持续
指标not_disclosed已检查约定范围但公司未披露数值为零
指标conflicting指标值或定义在来源间冲突可以直接计算平均值
指标not_applicable该指标不适用于此业务或期间为了提高覆盖率而删除
Gate 结果等级
结果含义读者动作
pass关键问题在约定范围内已有充分、一致证据仍需关注失效条件与时效
pass_with_scope仅在明确边界内通过，边界外未验证先读 scope，不能外推
provisional暂定结果：现有证据支持工作假设，但关键验证尚未完成不得当作 pass 或最终结论
range_only只能支持区间，无法支持单点值保留上下界和敏感性
inconclusive现有证据无法判定列出缺口，等待新证据
fail关键证据否定该 Gate，或触发硬性失败条件整体不能升级为决策级
整份报告的发布状态
状态含义
source_partial主源尚未收齐，事实底座不完整
research_in_progress证据桥、维度或模型仍在补齐
needs_human_review机器校验已完成或基本完成，但具名人工复核尚未闭环
production_reviewed来源、模型、红队、校验和具名人工复核均达到发布要求
最容易误读的三点：applicable 不等于“正面”，observed 不等于“优秀”，provisional 不等于“通过”。

统一母版也是发布 Gate
