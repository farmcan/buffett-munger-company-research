# 美图公司（01357.HK）研究包

研究快照：2026-08-04（Asia/Shanghai）

行情锚点：2026-08-03 完整收盘，HK$4.77

研究边界：公开资料、非投资建议

## 先回答两个问题

1. **完全摊薄的每股 owner earnings 能否复合十年？** 机制可理解，证据尚不够长。正向链是付费用户 → ARPU/credits → 生产力与海外收入 → 毛利和费用杠杆 → 每股 owner earnings；反向链是模型/平台替代、渠道与推理成本、SBC、可转债和奖励稀释。H1 预告加强了未来一两年的盈利证据，但没有证明留存、单位经济性或十年定价权。若以 FY2025 基础 OE、含 CB 的保守摊薄上限和十年后 18× Price/OE 计算，要让价格本身十年年化 10%（不计分红和净现金变化），每股 OE 约需年化增长 11.9%。
2. **HK$4.77 是否提供足够预期回报和安全边际？** 当前没有基础情景安全边际。FY2025 基本股口径 Price/OE 约 18.2—19.9×；由 H1 预告转换出的 FY2026 严格经济盈利代理对应约 17.2—21.0×。更新后的资本结构一致 DCF 为 HK$2.48 / 5.04 / 7.31，基础值只比现价高约 5.7%，不足以覆盖 H1 未审阅输入、留存/AI 成本未知、同行口径不足和奖励重叠。

因此当前研究路由是 **`verification_watchlist`**，发布状态仍为 **`needs_human_review`**，不是决策级结论。

## 2026H1 新证据

- 7 月 30 日官方初步更新披露：6 月 MAU 约 2.82 亿，付费用户超过 1,844 万；生产力约 235 万（同比 +29.8%），休闲约 1,609 万（+18.8%）。
- AI 生产力 ARR 约人民币 6.2 亿元（+47.8%）；AI credits 消耗在 Q1、Q2 都环比增长超过 46%。ARR 和用量不是确认收入或毛利。
- H1 核心业务收入约人民币 18 亿元（+30.9%）；生产力收入 +40.1%、占比超过 18%，休闲收入 +32.3%、占比约 82%。
- 公司调整后归母利润预计同比 +36%—40%，IFRS 归母至少 +35%。按 2025H1 基数机械推导，调整后归母约 6.36—6.54 亿元。
- 反方细节：生产力付费用户从 Q1 约 234 万到 6 月约 235 万，两次都是约数，几乎没有可识别的环比净增；生产力 ARR 同期约增长 6.9%，公司也确认 ARPU 上升。因此 Q2 更像用量/货币化改善，而非用户净增加速。
- 公告基于未经审核和未经审阅的管理账；毛利率、渠道/模型成本、SBC、CFO、合同负债、净现金与同日摊薄股数仍待 8 月 26 日正式中报。

## 巴芒框架下仍未通过的部分

- 留存、分产品/地区 ARPU、CAC、credits 复购与单位毛利未披露。
- 毛利、经营现金流、SBC 和模型/渠道成本尚未把调整利润桥接到真正赚的钱。
- 通用模型、OpenAI/Google、Adobe/Canva 和操作系统入口都可能把单点生成/编辑功能商品化；美图必须用工作流、分发、审美/本地化和结果闭环证明不可替代性。
- 回购和创始人增持是利益一致信号，不是免检章；CB 全转换、奖励和库存股恢复供给必须进入 fully diluted 每股桥。
- 历史 PE/PB/EV 仍缺无前视偏差的点时序列；大幅回撤不自动构成安全边际。
- 研究包已覆盖固定 25 个维度、50 个指标族和九道 gate，但仍缺具名人工复核、产品 cohort 和至少三家同口径直接同行。

## 数据口径

- 财务优先使用 HKEX 年报、中报和公司正式公告；公司新闻稿只作补充。
- “调整后利润”是公司定义，不等同于 owner earnings；员工 SBC 始终视为股东经济成本。
- 行情使用腾讯前复权日线，估值末日为 2026-08-03；8 月 4 日盘中 bar 明确排除。中国银行汇率快照为 2026-08-04 CNY 0.8660/HKD。
- SFC 周度数据是达到申报门槛的净空仓，不是全部市场空仓、借券使用率或每日卖空成交。
- 事件窗口区分完整 `T-1 → T0 → T+5` 与尚未完成的 partial window；重叠事件只记录共振，不做单因果归因。
- 历史估值必须使用当时已知盈利、股本和 FX 重建；当前不声称精确历史分位。
- DCF、FY2026 和十年情景都是可证伪的敏感性分析，不是目标价、收益承诺或买卖指令。
