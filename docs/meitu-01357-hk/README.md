## 先回答两个问题

1. **完全摊薄的每股 owner earnings 能否复合十年？** 机制可理解，证据尚不够长。正向链是付费用户 → ARPU/credits → 生产力与海外收入 → 毛利和费用杠杆 → 每股 owner earnings；反向链是模型/平台替代、渠道与推理成本、SBC、可转债和奖励稀释。H1 预告加强了未来一两年的盈利证据，但没有证明留存、单位经济性或十年定价权。若以 FY2025 基础 OE、含 CB 的保守摊薄上限和十年后 18× Price/OE 计算，要让价格本身十年年化 10%（不计分红和净现金变化），每股 OE 约需年化增长 11.9%。
2. **HK$4.75 是否提供足够预期回报和安全边际？** 当前没有基础情景安全边际。FY2025 基本股口径 Price/OE 约 18.16—19.78×；由 H1 预告转换出的 FY2026 严格经济盈利代理对应约 17.10—20.88×。更新后的资本结构一致 DCF 为 HK$2.48 / 5.04 / 7.31，基础值比现价高约 6.1%（现价比基础值低约 5.75%），不足以覆盖 H1 未审阅输入、留存/AI 成本未知、同行口径不足和奖励重叠。

因此当前研究路由是 **`verification_watchlist`**，发布状态仍为 **`needs_human_review`**，不是决策级结论。

## 模型竞争与商业化

- **模型变强同时产生四股力量：**AI 创作需求扩容、单点功能被通用入口替代、模型/API/渠道抽取利润，以及美图能否把能力产品化并卖给高频、有明确 ROI 的客户。“使用 AI 的人变多”只增加总需求，不自动增加美图的工作流份额、付费、留存或贡献利润。
- **“Claude 熄火”尚无充分证据，更准确的是相对领先正在被快速追平。** Anthropic 仍在发布模型并直接商业化 Claude Code；OpenAI、Google、Qwen 等同时推进模型能力、降价、开放权重和应用入口，市场从单点领先转向多极拉锯。
- **模型产业存在两条同时发生的路径。** 一条是模型厂商向下吞应用和企业席位，使薄功能 SaaS 面临替代；另一条是模型厂商继续砸钱追赶、降价和开源，把模型层打成更接近公共品，为应用带来“DeepSeek 时刻”。当前更接近“模型竞争强、向下应用化也强”的混合象限。
- **中国模型可能已经进入“更强 → 更多使用与开发者 → 更多反馈和投入 → 更便宜、更强”的加速飞轮。** Qwen Code 的周度发布和 DeepSeek V4 的公开能力/低价支持这一方向；若竞争、开放生态、资本投入和推理优化继续，飞轮可能持续数年。但算力与芯片、数据边际收益、监管版权和模型层现金流都可能令它减速，所以这是基准情景而非确定事实。
- **应用层存在反直觉背离：客户得到的结果越来越好，应用自身独占贡献的比例却可能越来越低。** 当生成、编辑、审美判断和 Agent 编排逐步成为模型标准能力，美图的体验和使用量可以上升，功能护城河、定价权和利润池却下降。关键不只是成品质量，而是去掉底层模型后，美图还能独占贡献多少客户数据、审美反馈、素材、工作流、分发和交易结果。
- **很多应用会收敛为“模型封装 + 工作流 + 销售”，仍可能是高利润、高 ROIC 生意。** 应用替客户完成模型路由、界面、模板、质量控制、支付、售后和行业销售，又无需承担前沿训练的巨额固定投入；如果已有品牌和自然流量，模型降价可以转化为利润。但低投入也意味着低进入壁垒，同模型竞争、买量、渠道抽成和模型厂商直销可能迅速摊薄利润。因此要把当期利润池与十年护城河分开。
- **对美图的净判断是“成本红利 + 竞争升级 + 能力上移”。** 真正的应用层红利需要单位成功任务成本下降、多模型可替换或自托管，同时模型厂商没有完全截走终端入口。决定胜负的稀缺环节已经从开发功能迁移到分发、工作流、客户数据、销售效率、留存续费和企业扩购。

完整四象限、客户任务与验证指标见 [报告的核心命题章节](./report.html#value-capture)。

- 公告基于未经审核和未经审阅的管理账；毛利率、渠道/模型成本、SBC、CFO、合同负债、净现金与同日摊薄股数仍待 8 月 26 日正式中报。

## 上市以来历史大涨账本

- 按“60 个交易日内由局部收盘低点上涨至少 50%，同一催化制度下重叠窗口合并”的统一规则，共识别 13 轮主升；另记录 10 轮涨幅 30%—50% 的次级反弹。起止点是事后研究窗口，不是实时交易信号。
- 2017 年真正突破 HK$20 的只有 3 月 20 日盘中：最高 HK$23.05、收盘 HK$15.98。主要原因是纳入港股通后南下资金、低流通盘与投机情绪共振，不是盈利证明。
- 2022 年后逻辑发生质变：AI 绘画和 AIGC 先带来产品/行业重估，2023H1、FY2023、FY2024 盈喜与 2025H1 盈喜再把叙事接到订阅、毛利和利润。2025 年“DeepSeek → 阿里合作 → RoboNeo → H1 盈喜”是 AI 时代证据最完整的组合，但 2025 年盘中峰值仍只是 HK$12.56。
- 持续性是最大的反证：13 轮主升在阶段高点后的 20 个交易日，收盘收益全部为负，中位数 −16.8%；期间最大回撤中位数 −24.0%。历史表明产品、模型和资金负责点火，付费、毛利、现金流与完全摊薄每股利润才决定能否抬高下一轮底部。
- 2020 年 4—7 月、2021 年 8—9 月和 2022 年 4—6 月没有找到足以解释全段的硬催化，已明确标为 source gap，没有用成交放大或价格相关反推单一原因。

## 数据口径

- 财务优先使用 HKEX 年报、中报和公司正式公告；公司新闻稿只作补充。
- “调整后利润”是公司定义，不等同于 owner earnings；员工 SBC 始终视为股东经济成本。
- 行情使用腾讯前复权日线，估值末日为 2026-08-07；8 月 7 日为最新完整交易日。中国银行汇率快照仍为 2026-08-04 CNY 0.8660/HKD，汇率未在本次更新中重取。
- SFC 周度数据是达到申报门槛的净空仓，不是全部市场空仓、借券使用率或每日卖空成交。
- 事件窗口区分完整 `T-1 → T0 → T+5` 与尚未完成的 partial window；重叠事件只记录共振，不做单因果归因。
- 历史大涨采用前复权收盘价、统一阈值和恒指同窗基准；公司硬催化、行业主题、流动性/政策和 source gap 分开标记，局部高低点只作事后归因研究。
- 历史估值必须使用当时已知盈利、股本和 FX 重建；当前不声称精确历史分位。
- DCF、FY2026 和十年情景都是可证伪的敏感性分析，不是目标价、收益承诺或买卖指令。
