1. 长期档案：十年所有者问题

第一问不是 AI 热不热，而是完全摊薄后的每股所有者收益能否跨光纤周期增长；第二问才是当前价格有没有安全边际。

支持：一体化制造、全球产能、海外收入、光互联组件与空芯光纤，使公司不再只是普通单模光纤价格接受者。
反证：历史利润随 ASP 和运营商资本开支波动；AI 收入纯度、有效产能、维护性投入和增量 ROIC 尚未披露。

长期结论：经营拐点已进入数据，但“耐久护城河 + 每股 owner earnings + 安全边际”三项还不能同时通过。

14. 护城河与技术期权：空芯光纤不能提前资本化

0.04 dB/km、长距离拉制、试点和产业链一体化是技术进展；但没有商业规模、ASP、毛利和客户复购，就不能把它直接加入基准盈利。最可靠的跟踪顺序是：试验 → 商用链路 → 重复订单 → 收入占比 → 毛利 → 资本回报。
