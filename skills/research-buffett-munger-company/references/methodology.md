## 1. 定位

本项目不是语录库、人格模拟器、选股机器人或固定打分模型。它做两件事：

1. 从 Berkshire Hathaway 官方文件、经授权的年会档案和公开活动记录中提取可归因的决策
   原则；
2. 为这些原则补上现代公司研究需要的证券身份、证据、会计、行业和 QA 控制。

第二部分是本项目的工程化，不应伪装成巴菲特或芒格逐字提出的 checklist。

完整来源、访问快照、claim 映射与权利边界保存在
`methodology-source-ledger.json`；方法到生产字段的逐项关系保存在
`methodology-implementation-crosswalk.json`。

## 3. 可由主源支持的核心原则

### 3.1 把股票视为企业所有权

[Berkshire Owner's Manual](https://www.berkshirehathaway.com/ownman.pdf) 强调股东是企业的
所有者合伙人，并把长期目标落到每股内在价值增长。本项目因此先解析法律发行人、股份类别、
控制权、少数股东权益与完全稀释股本，再讨论估值。

工程含义：

- 公司规模增长不等于每股价值增长；
- A/H、红筹、VIE、母子公司和交叉持股必须先去重；
- 增发、回购、并购和留存收益都要审计每股结果。

### 3.2 只研究能理解且长期经济可判断的企业

[1977 Chairman's Letter](https://www.berkshirehathaway.com/letters/1977.html) 与
[1996 Chairman's Letter](https://www.berkshirehathaway.com/letters/1996.html) 支持对
可理解业务、长期前景、管理层和价格的关注，并强调不需要对所有公司都有看法。

工程含义：

- 无法解释客户、付费原因、成本、资本需求和主要失效变量时，返回 `outside_circle`；
- 能力圈是研究边界，不是行业标签；
- 不以“我熟悉这个品牌”代替单位经济和产业链证据。

### 3.3 好生意的长期经济性优先于表面便宜

[1989 Chairman's Letter](https://www.berkshirehathaway.com/letters/1989.html) 讨论了优质
企业与“雪茄烟蒂”式便宜企业的差别；
[2023 Shareholder Letter](https://www.berkshirehathaway.com/letters/2023ltr.pdf) 回顾了
芒格推动 Berkshire 转向以合理价格持有伟大企业的作用。

工程含义：

- 低 PE、低 PB 或大跌只是调查触发器；
- 必须验证资本回报机制、再投资跑道和竞争反应；
- 周期顶部的低 PE、会计利润或一次性收益不能自动升级为价值。

### 3.4 护城河必须是可持续机制

[2007 Chairman's Letter](https://www.berkshirehathaway.com/letters/2007ltr.pdf) 讨论了
长期竞争优势与经济“护城河”。本项目将其拆成客户愿付、转换成本、网络效应、成本优势、
有效规模、许可与流程/资产优势。

工程含义：

- 高毛利、市占率和品牌排名只是线索；
- 必须解释竞争者为什么不能夺走超额回报；
- 必须保存价格战、替代技术、客户自研、渠道变化和监管变化等反证；
- 结论必须回答护城河在变宽、稳定还是变窄。

### 3.5 资本回报和增量资本效率比 EPS 增长更重要

[1977 Chairman's Letter](https://www.berkshirehathaway.com/letters/1977.html) 说明单看
每股收益增长可能产生误导，需要结合权益资本和资本回报；
[1983 Chairman's Letter](https://www.berkshirehathaway.com/letters/1983.html) 强调每股
价值、股份发行和股东所有者视角。

工程含义：

- 计算 ROE、ROIC 时保存分子、分母、期间和会计范围；
- 区分存量回报与增量 ROIC；
- 判断增长靠内生高回报再投资、杠杆、并购还是股权融资；
- 审计留存的一元是否创造超过机会成本的每股价值。

### 3.6 Owner earnings 是经济概念，不是固定报表行

[1986 Chairman's Letter](https://www.berkshirehathaway.com/letters/1986.html) 给出 owner
earnings 的经典思路，并指出维持长期竞争地位所需资本支出存在估计困难。

通用表达：

```text
正常化的归母利润
+ 可归属且真实的非现金费用
- 维持竞争地位所需资本开支
- 维持正常业务所需增量营运资本
= owner earnings 区间
```

工程含义：

- 不把 EBITDA 或 CFO-capex 机械当成 owner earnings；
- 维护性资本开支不披露时使用区间；
- 股权激励、资本化研发、商誉减值、租赁和并购营运资本逐项判断；
- 金融企业改用法定资本、准备金、偿付能力和可上划现金。

### 3.7 管理层质量通过长期资本配置和坦诚度验证

[Owner's Manual](https://www.berkshirehathaway.com/ownman.pdf)、
[1983 Chairman's Letter](https://www.berkshirehathaway.com/letters/1983.html) 和
[2011 Chairman's Letter](https://www.berkshirehathaway.com/letters/2011ltr.pdf) 支持
对资本配置、回购、股份发行、债务和管理层沟通的审视。

工程含义：

- 对照历年承诺与实际；
- 分析再投资、并购、分红、回购、增发、债务和闲置现金；
- 回购是否增值取决于价格与内在价值，不是天然利好；
- 激励、关联交易和少数股东待遇是治理证据，不由管理层措辞覆盖。

### 3.8 先保证生存，再讨论复利

[Owner's Manual](https://www.berkshirehathaway.com/ownman.pdf) 与多封 Berkshire 股东信
反复强调避免威胁长期生存的债务和风险。

工程含义：

- 评估债务到期、利息覆盖、担保、租赁、受限现金和表外安排；
- 对金融、地产、资源和公用事业使用行业专用压力测试；
- 正常情景下的高回报不能抵消尾部融资断裂。

### 3.9 内在价值是区间，不是精确目标价

[Owner's Manual](https://www.berkshirehathaway.com/ownman.pdf) 将内在价值定义为企业未来
可取出现金的折现价值，并承认估计会因人和时间而变化。

工程含义：

- 显式记录增长、利润率、再投资、折现率、终值和股本；
- 使用低/base/高情景与敏感性，不伪造概率；
- 使用反向估值回答当前价格隐含了什么；
- 安全边际随商业、会计、治理和估值不确定性变化，不设全行业固定比例。

### 3.10 逆向、激励与心理误判是 red-team 工具

Berkshire 发布的
[Poor Charlie's Almanack excerpts](https://www.berkshirehathaway.com/letters/2024ltr.pdf)
与可追溯的公开演讲记录支持逆向、激励与多模型思考的重要性。非官方转录链只作补充。

工程含义：

- 先写最强反对意见；
- 问“什么会永久毁掉企业或每股价值”；
- 识别奖励导致的行为、确认偏误、承诺一致、社会认同和模型单一化；
- 把反证写成可观察的失效条件与下一验证事件。

## 4. 从“道”到“术”

本项目把原则连接到可执行顺序：

```text
企业所有权
  -> 证券与法律主体
能力圈
  -> 商业模式、客户、供应商、单位经济
优质企业
  -> 多年经济性、护城河、增量资本回报
所有者收益
  -> 利润质量、现金转换、维护性再投资
资本配置
  -> 再投资、并购、分红、回购、融资、每股结果
生存优先
  -> 杠杆、期限、表外、监管资本、尾部压力
内在价值
  -> 情景区间、反向预期、敏感性、安全边际
逆向
  -> 独立 red-team、失效条件、下一验证点
```

其中，客户集中、供应商、审计、税务、逐项 source hash、固定 artifact schema 等细节是为了
让研究可复现而增加的工程控制。

## 5. 不能归因给巴菲特或芒格的内容

以下常见做法不能仅因出现在开源项目中就写成“大师规则”：

- ROE 必须高于某个固定百分比；
- 债务权益比必须低于某个固定数；
- 护城河、管理层、可预测性按固定权重加总；
- 所有行业使用统一 DCF 参数或安全边际；
- 低于某 PE 就买入；
- 多 agent 投票等于证据；
- 近期涨跌、技术指标或社交情绪决定长期价值；
- 模型输出具体买卖、仓位或保证收益。

这些可以作为待验证假设或工程设计，但必须标明作者来源，不能归因给 Buffett/Munger。

## 6. 九 gate 的设计依据

| Gate | 主问题 | 方法依据 | 主要工程补充 |
| --- | --- | --- | --- |
| 身份与来源 | 买到什么、证据是什么 | 所有者视角 | 证券主数据、日期、hash、scope |
| 能力圈 | 能否解释企业 | 可理解与可预测 | 客户、供应商、单位经济、会计难点 |
| 商业经济 | 长期回报如何形成 | 资本回报与好生意 | 多年三表、分部、增量 ROIC |
| 护城河 | 超额回报为何持续 | 持久竞争优势 | 客户行为、同行反证、方向 |
| 管理与资本配置 | 每股价值是否增加 | 坦诚、理性配置 | 关联方、激励、稀释、承诺兑现 |
| Owner earnings | 所有者能取出多少现金 | owner earnings | 维护性 capex 区间、行业分支 |
| 生存 | 坏情景能否活下来 | 避免永久损失 | 到期、担保、监管资本、压力测试 |
| 内在价值 | 当前价格隐含什么 | 折现现金与安全边际 | 情景、敏感性、反向估值 |
| 决策与反证 | 为什么会错、下一步是什么 | 逆向与机会成本 | 独立 red-team、状态机、人工复核 |

## 7. 与 25 个研究维度的关系

25 个维度中：

- `primary_method`：问题本身直接来自有主源支持的方法；
- `mixed`：主源决定问题，本项目增加证据和会计控制；
- `seed_operating_control`：为防漏查或误推断增加，不归因于 Buffett/Munger。

当前 crosswalk 固定为：

- 7 个 `primary_method`；
- 12 个 `mixed`；
- 6 个 `seed_operating_control`；
- 共 25 个维度、50 个最低 indicator families、9 个 gate；
- 21 个方法 claim 全部有映射；
- GitHub 方法权威数为 0。

这些数字是当前 contract 版本，不是对企业质量的评分权重。

## 8. 使用边界

- 本项目不自动取得公司数据；研究者必须使用有权访问的主源。
- validator 检查结构、引用、日期、公式和状态一致性，不能证明输入事实真实。
- 高质量研究仍需要行业知识、独立反证和具名人工复核。
- 方法不适合用同一套工业指标机械覆盖银行、保险、地产、资源、监管公用事业或未盈利生物科技。
- 通过所有 gate 只表示研究过程达到预设标准，不表示应买入，也不保证回报。
